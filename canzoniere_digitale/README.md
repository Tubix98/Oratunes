# Canzoniere Flutter 🎵

> Un'applicazione moderna e performante per visualizzare, gestire e trasporre testi di canti con accordi, costruita con Flutter e basata su principi di Clean Architecture.

Questo progetto nasce dall'esigenza di avere uno strumento flessibile per musicisti che utilizzano la notazione latina (Do, Re, Mi...) e necessitano di funzionalità avanzate come la trasposizione in tempo reale.

## ✨ Funzionalità Principali

- **Visualizzazione Chiara:** Testo e accordi formattati per una leggibilità ottimale.
- **Trasposizione in Tempo Reale:** Aumenta o diminuisci la tonalità del canto con un semplice tocco.
- **Supporto Notazione Latina:** Scrivi e visualizza gli accordi nel formato "Do, Re, Mi...", anche dopo la trasposizione.
- **Controlli Rapidi:** Un'interfaccia `SpeedDial` permette di accedere rapidamente alle funzioni principali (trasposizione, mostra/nascondi accordi, auto-scroll).
- **Architettura Solida:** Il codice è organizzato seguendo i principi della Clean Architecture, separando dati, logica di business e interfaccia utente.

## 🛠️ Tecnologie Utilizzate

- **[Flutter](https://flutter.dev/)** - Il framework UI di Google per creare app native multi-piattaforma.
- **[Dart](https://dart.dev/)** - Il linguaggio di programmazione ottimizzato per le app client.
- **[flutter_speed_dial](https://pub.dev/packages/flutter_speed_dial)** - Per creare un'interfaccia con azioni rapide e animate.
- **Clean Architecture** - Come principio guida per una struttura del codice scalabile e manutenibile.

## 🚀 Come Iniziare

Per eseguire il progetto in locale, segui questi passaggi.

### Prerequisiti

Assicurati di avere installato il [Flutter SDK](https://flutter.dev/docs/get-started/install).

### Installazione

1.  Clona il repository sul tuo computer:
    ```bash
    git clone [https://github.com/TUO_NOME_UTENTE/NOME_PROGETTO.git](https://github.com/TUO_NOME_UTENTE/NOME_PROGETTO.git)
    ```
2.  Entra nella cartella del progetto:
    ```bash
    cd NOME_PROGETTO
    ```
3.  Installa le dipendenze:
    ```bash
    flutter pub get
    ```
4.  Avvia l'applicazione:
    ```bash
    flutter run
    ```
